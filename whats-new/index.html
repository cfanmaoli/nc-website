History of changes

The complete, always up-to-date list lives in WHATS_NEW.md and on the releases page.

1.9.3b (2026):

  • New “Import settings”: Preferences → General can import preferences, saved tabs, network connections, language packs and syntax highlighting from the original Nimble Commander app; the current settings are backed up first and the app restarts afterwards.
  • Compression targets are claimed exclusively: if the chosen name is taken after the scan, the next free name is used, and failure cleanup only removes files created by the job.
  • Language-pack validation rejects dynamic width/precision (%*d, %.*f) instead of treating them as literal percent signs; the update feed cache is keyed by asset ID and verified by digest.
  • Fixed the fake-helper test that left a stale helper cache and failed the nightly CI; the Unsigned build now produces the same app and executable name as the release build, so they share one configuration directory.
  • This release is signed with a development certificate, so Administrator Mode can be enabled normally.

1.9.3a (2026):

  • Safer Trash: emptying refuses a .Trashes chain that leads through a symlink or a mount point and deletes through pinned directory descriptors; “Put Back” re-checks the resolved destination.
  • When a directory changes while it is being read, the appended entries are always sorted with the display comparator - names with non-ASCII characters or a different display form can no longer land in the wrong place.
  • Fixed a deadlock between the volume-unmount handler and background watch registration.
  • RAR component hardening: protocol negotiation, bounded list/link/read timeouts, no inherited file descriptors; a failing component falls back to the built-in reader.
  • A failed compression setup now releases the archive and removes the half-written file.
  • Language packs are validated by argument position and exact conversion type: literal percent signs no longer cause valid translations to be skipped, while %n or a mismatched argument is still refused.
  • This patch release is signed with a development certificate, so Administrator Mode can be enabled normally.

1.9.3 (2026):

  • Optional RAR support through the separate ncrar-helper component: solid archives, encrypted headers and payloads, multi-volume sets; a single switch in Preferences → Compression with the component's status and version.
  • Compression preferences: the default archive format (zip, 7z, tar), the algorithm and the level used by the compress dialog.
  • Third-party libraries rebuilt with the current toolchain; zlib updated to 1.4.
  • Russian is no longer a built-in language; translations for other languages live in the nc-language repository.

1.9.2 and earlier:

  • Simplified Chinese localization out of the box (about 1,460 strings).
  • Language packs: export the current interface strings, import a translation, switch languages without rebuilding the app.
  • Extra bundled themes: Solarized, Nord, Dracula, Gruvbox, One Dark, Tokyo Night, Catppuccin, GitHub Dark and Monokai.
  • Flat view of an entire subtree, performance work on listings and the UI.

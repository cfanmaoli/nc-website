Installation and uninstallation

To install

Open the downloaded .dmg and drag “Nimble Commander-Fork.app” into the Applications folder.

To uninstall

Select the app in Applications in Finder and choose “Move to Trash”.

The build is not notarised. If macOS blocks it after a download, either right-click the app and choose “Open” once, or clear the quarantine attribute:

xattr -dr com.apple.quarantine "/Applications/Nimble Commander-Fork.app"

Optional RAR support

RAR archives are read by the built-in reader out of the box. For solid archives, encrypted headers and multi-volume sets, install the separate ncrar-helper component: it is an independent program whose own code is MIT-licensed, while the UnRAR sources it bundles remain under the UnRAR license — so the application itself still contains no proprietary code. After installing it, enable it in Preferences → Compression; the same pane shows whether it is installed and which version it is.

The component is not notarised either; if macOS quarantines it, clear the attribute as well:

xattr -dr com.apple.quarantine /Applications/ncrar-helper.app

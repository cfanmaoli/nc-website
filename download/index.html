Direct download

Nimble Commander-Fork is published on GitHub Releases: download the latest .dmg, and check it against the .sha256 file on the same page.
The build is for Apple Silicon only and requires macOS 12 or later.

DOWNLOAD

Installation and uninstallation

To install Nimble Commander-Fork open the downloaded .dmg and drag “Nimble Commander-Fork.app” to the Applications folder. To uninstall it select the app in Applications using Finder and choose “Move to Trash” from the context menu.

The build is not notarised. If macOS blocks it after a download, either right-click the app and choose “Open” once, or clear the quarantine attribute:

xattr -dr com.apple.quarantine "/Applications/Nimble Commander-Fork.app"

Optional RAR support

RAR archives are read by the built-in reader out of the box. For solid archives, encrypted headers and multi-volume sets, install the separate ncrar-helper component: it is an independent program under the UnRAR license, so the application itself still contains no proprietary code. After installing it, enable it in Preferences → Compression; the same pane shows whether it is installed and which version it is.

Languages

The app ships English and Simplified Chinese. Translations for other languages are collected in nc-language: download the JSON file for your language, import it via Preferences → Language → Import Language File… and restart. A partial translation is fine.

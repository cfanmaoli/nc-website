How Can We Help You?

If you run into a problem or have a question about Nimble Commander-Fork, use the GitHub issue tracker or the discussions. Please include the app version, your macOS version and, when possible, the steps to reproduce the problem.

Issue tracker

Bug reports and feature requests on GitHub Issues.

Discussions

Questions, ideas and general feedback in GitHub Discussions.

Source code

Browse the code and send changes on the GitHub repository.

User guide

The in-depth online guide: Docs/Help.md.

Extra components have their own repositories: nc-language for translations and ncrar-helper for the optional RAR support.

The original Nimble Commander is supported by its author on magnumbytes.com.

Multilingual support

The app ships English and Simplified Chinese. Translations for other languages are community-maintained and collected in nc-language: pick a language below and the button opens its JSON file.

Download language file

The button opens the language's JSON file in a new tab; save it and import it via Preferences → Language → Import Language File…, then restart the app.

About the translations

Most of these translations were bootstrapped with machine translation and have not been reviewed by native speakers, so mistakes and awkward phrasing are expected. If you fix one, open a pull request in nc-language; the repository's README explains the format and the workflow.

Entries are matched by bundle, table and key; empty entries fall back to English, so a partial translation is fine.

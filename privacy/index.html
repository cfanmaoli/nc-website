Privacy Policy

Nimble Commander-Fork is a desktop application and a static website. The application does not collect, transmit or sell any personal data: it contains no analytics, no telemetry and no advertising. Its settings, language packs and the optional RAR component stay on your Mac.

This website is served by GitHub Pages. There are no cookies, no analytics and no tracking scripts. GitHub may keep standard server logs (such as IP addresses) as described in the GitHub Privacy Statement.

The optional ncrar-helper component and the nc-language files are ordinary local programs and data; they do not send anything over the network either.

If you have questions about this policy, open an issue on GitHub.
